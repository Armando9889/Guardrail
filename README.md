Guardrail è un plugin per DevStack che estende le funzionalità di controllo delle istanze OpenStack Nova attraverso un sistema automatizzato di verifica della conformità alle politiche definite dall'amministratore. Il servizio esegue scansioni periodiche o manuali, applica otto regole relative a metadati, risorse, immagini, denominazione e stato delle VM, e registra le violazioni in un database SQLite. In presenza di violazioni critiche, può attivare una procedura di quarantena automatica mediante Neutron, limitando la connettività di rete delle istanze interessate. Un'API REST consente di consultare i risultati, gestire le regole e monitorare le azioni eseguite, con autenticazione e autorizzazione delle operazioni amministrative. L'architettura modulare consente di integrare i servizi OpenStack coinvolti e di verificare separatamente i controlli, la gestione delle anomalie e le operazioni di isolamento.
